# 🏆 HSLegendArriver

**读取炉石日志 + 获取炉石盒子打法建议 + 自动执行操作**

当前版本 **v1.3.26** ｜ 识别链路：**RapidOCR + PP-OCRv6（ONNX Runtime）**

**33 分钟：钻石 2 → 传说** ｜ **一下午：冲到传说约 6000 名**

> 🔥 已实测支持：**机械骑 / 号角骑 / 弃牌术 / 海盗瞎**
> 🩺 无人值守安全：炉石闪退 / 卡死会告警并**自动停止**，不会对着失效画面空转到天亮
> 🔄 卡住自动重开：日志超过设定秒数不更新就重启炉石并重开一局（带次数上限）
> 🎯 认出对面是哪套卡组就立刻投：特征牌 + 「与/或/非」任意嵌套，**只判对方**
> ⌨️ **Ctrl+Q 随时急停**：任何界面都有效
> 🧪 第一次启动就自检：Python、依赖、管理员、分辨率、日志目录逐项 ✅/❌

## ⚠️ 先看三条（最容易翻车的配置）

| # | 要求 | 不满足会怎样 |
| - | --- | --- |
| 1 | **Python 必须 3.12（64 位）** | 项目与 OCR 依赖只在 3.12 上验证过；3.13+ 能点「开始游戏」，但一进对局就卡在换牌 |
| 2 | **炉石窗口设成 1920×1080**（窗口化即可，**不要用「最大化」**），然后**校准一次** | 客户区不是 16:9 会把点击横向拉偏；尺寸不对自检会提示 |
| 3 | **用管理员权限启动** | 游戏不接受普通权限进程的鼠标注入，现象是「脚本在跑、点了没反应」 |

> 屏幕分辨率与缩放随便：脚本按「炉石客户区几何」实时换算坐标，4K / 2K + 150% 缩放都能跑。
> 要固定的是**炉石窗口自己的客户区 = 1920×1080**。
> 另外项目路径**不要有中文字符**（OCR 与依赖对中文路径支持不好）。

## 🚀 快速开始（4 步）

**1. 装 Python 3.12** —— [python.org](https://www.python.org/downloads/) 下载安装，务必勾选 `Add python.exe to PATH`。

**2. 装依赖**（项目根目录开 PowerShell）：

```powershell
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**3. 管理员身份启动**：

```powershell
cd 项目根目录
python web_ui.py
```

默认打开一个**原生窗口**（WebView2，地址 `http://127.0.0.1:8765`）：**关闭窗口即退出**，重复启动只会把已有窗口切到前台；WebView2 不可用时自动退回浏览器。端口被占用会往后顺延（8765–8785）。

> 只想起 HTTP 服务（开发 / 远程看页面）：`python web_ui.py --no-browser`

**4. 打开炉石 + 炉石盒子** —— 盒子用**简体中文**，左侧「推荐打法」面板要完整显示、不被遮挡。

> 想省掉每次 UAC：`python hsctl.py serve install-task`（管理员跑一次），之后启动不再弹框，手机/agent 远程也能用。

## 🎮 第一次使用（5 步）

1. **填账号**（⚙ 设置 → 账号）：用户 ID 必须是**当前账号完整的战网昵称，含 `#编号`**；日志目录选炉石安装目录下的 `Logs`，点「检测」验证。
   > 昵称填错 → 脚本读不出「我是谁」，整局不出牌。换账号务必同步改。
2. **校准**：⚙ 设置 → 校准 → 「📐 打开校准」，把绿框拖到盒子「推荐打法」面板上，按 **S** 保存（详见下节）。
3. **看自检**：⚙ 设置 → 环境自检，全绿再继续；❌ 项按提示修。
4. **开始运行**：点「⚔️ 开始运行」→ 打开日志浮窗、把炉石切到前台，**此时不会自动开打**。
5. **开始对战**：按钮变成「⚔️ 开始对战」，再点一次（二次确认）才真正开始。随时 **Ctrl+Q** 急停。

## 🎯 校准（只需一次）

自动化没在跑的时候打开校准窗口：屏幕上只画**当前目标那一个框** + 屏幕正中央的目标条 + 右侧推荐区域实时 OCR 预览，并提示「请对齐相应UI」。

| 操作 | 说明 |
| --- | --- |
| **Tab** | 切换目标 |
| 拖动 | 抓框体 / 右下角手柄改位置与大小；抓目标条标题可把整条挪开（仅本次有效） |
| **S** | 保存到 `ui_config.json`（不覆盖昵称 / 日志目录 / 延时） |
| **Esc** | 退出 |

**13 个目标**：盒子推荐面板、换牌推荐面板（最多 4 张留牌）、换牌确认按钮、AI 胜率浮动条（兜底区域自动外扩）、结算「开始」按钮、段位数字、主界面「传统对战」、选择套牌标题、9 个卡组格、四个模式盾牌。

- 框**以外**的画面保持**鼠标穿透**，可以边看游戏边调。
- 拖动 / 缩放炉石窗口时框会**实时跟着走**，校准一次之后窗口随便挪都不用重校。
- 浮窗上的「校准」按钮打开的是同一个窗口。

## 🖥️ 命令行控制（hsctl）

`hsctl` 是给命令行与 AI agent 用的薄客户端，**不碰** FSM / OCR / 浮窗逻辑，状态仍以控制台为准。

```powershell
python hsctl.py --version           # 版本号（v1.3.26）
python hsctl.py --json doctor       # 【会话第一条】自诊：环境 / 控制台 / 提权 / 下一步做什么
python hsctl.py status              # 阶段 / 账号是否匹配 / 战绩 / 参数
python hsctl.py log -f              # 实时跟随日志
python hsctl.py screenshot          # 抓一帧存 PNG 并返回路径
python hsctl.py ui                  # 当前在哪个界面（主界面 / 选择套牌）+ 匹配分
python hsctl.py enter-battle        # 拉起炉石 → 点传统对战 → 停在选择套牌
python hsctl.py start               # 开始对战
python hsctl.py stop --after-game   # 打完本局再停
python hsctl.py concede now         # 手动投降（运行中可用）
python hsctl.py surrender check     # 卡组识别：这一局每个条件满足没
python hsctl.py card 神秘           # 查卡名（本地 cards.json，不联网）
python hsctl.py delays set pre_action_delay_seconds=5   # 运行中热改参数
```

| 特点 | 说明 |
| --- | --- |
| 薄客户端 | 只调本地 JSON 接口；`card` / `surrender` 校验在本地跑，不需要控制台 |
| 端口自动发现 | 读 `log/ui_port.txt`，失效就扫 8765–8785 |
| 退出码 | `0` 成功 ／ `1` 业务失败 ／ `2` 参数错 ／ `3` 连不上控制台 ／ `4` 本机没有合格的 Python |
| 高风险要确认 | `restart-hearthstone` 必须 `--yes`（会结束炉石进程并清日志目录） |

## 🩺 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 脚本在跑但点了没反应 | 没用管理员启动 | 管理员 PowerShell 重开；或 `serve install-task` 装计划任务 |
| 一直不出牌 | 用户 ID 与战网昵称不一致 | 填完整昵称（含 `#编号`），看「账号校验」是否 ✅ |
| 换牌阶段反复重试 | 推荐面板没框对 / 被遮挡 | 重新校准；确认盒子面板完整可见 |
| 法术点不中目标 | 炉石用了「最大化窗口」 | 改回 1920×1080 窗口化（或全屏），重新校准 |
| 自检报 Python 版本不符 | 用了 3.13+ 或 32 位 | 换 3.12 64 位；`hsctl env pin` 指定解释器 |
| 启动报端口占用 | 8765–8785 被别的程序占了 | 关掉占用程序，或看控制台打印的实际端口 |
| 识别越来越慢 | 客户区太小，OCR 放大补偿吃性能 | 把炉石窗口设成 1920×1080 |

更多排查与逐项对照见 [docs/guide.html](docs/guide.html)。

## 📐 进阶：坐标怎么换算

所有点击坐标存的是**客户区相对位置**，运行时按「当前客户区尺寸 + 窗口在屏幕上的位置」换算成屏幕坐标，所以：

- 屏幕分辨率 / 缩放随便（4K、2K、150% 都行），窗口也不必贴左上角；
- 只要**炉石客户区是 1920×1080**、且**校准过一次**，窗口挪动不用重校；
- 客户区小于基准时会按比例补偿 OCR 放大（有上限，避免拖慢识别）。

## 🃏 进阶：对局中的特殊牌

| 场景 | 处理 |
| --- | --- |
| 星舰发射 | 识别发射按钮后单独点击，不当作普通随从 |
| 手牌目标（弃牌 / 选手牌） | 按盒子提示在己方手牌区选牌 |
| 抉择 / 发现 | 选完选项后再点它自带的目标（暮光侵扰、凶险梦魇、鲍勃「招募随从」） |
| 回溯 / 维持时间线 | 识别回溯提示后按推荐执行，不重复出牌 |
| 四选一 / 发现菜单 | 按盒子提示的序号选目标（克苏恩、鲍勃等） |

## ⏱️ 进阶：延时怎么调

⚙ 设置 → 延时，单位统一是秒：

| 参数 | 作用 |
| --- | --- |
| 换牌前等待 | 进入换牌后先等 N 秒再识图（默认 18） |
| 识别后缓冲 | 识别成功到点击之间 |
| 换牌重试间隔 | 面板未就绪 / 推荐不可执行时每轮等待 |
| 每回合前 | 新回合给盒子更新推荐留时间 |
| 操作后 | 一次操作到下轮 OCR 的间隔 |
| 抽牌额外（秒/张） | 回合内抽到牌时每张额外等待（回合开始那 1 张不算） |
| 选目标延时 | 选完选项到点目标之间 |

网络或机器慢导致识别跟不上时，优先加大「每回合前」与「操作后」。
